# b3ehive Codex Plugin

[中文](README.zh-CN.md)

Five swarm skills bound by one law (`core.md`) and one loop (`loop.md`).

| Skill | Use |
|---|---|
| `compete-cron-builder` | hard choices, repair search, audits, coverage; oracle-first selection |
| `execution-cron-builder` | one blueprint as a DAG; isolated workers; master acceptance |
| `learn-cron-builder` | understand, transform, translate, build a canon |
| `optimization-cron-builder` | measured performance loops or design research |
| `looper-cron-builder` | the shared loop and budget governance |

```bash
codex plugin marketplace add weiyangzen/b3ehive
codex plugin add b3ehive@b3ehive
```

Start a new Codex thread after installing. The skills under `skills/` are
generated copies; edit the root skill directories and run
`scripts/sync_codex_plugin.sh`. Full guide: the repository
[README](../../README.md).
